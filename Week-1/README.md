**Superstore Sales Data – Power BI**

**📌 Project Overview**
This project focuses on importing, cleaning, transforming, and preparing the Superstore Sales dataset using Power BI and Power Query. Various data transformation techniques were applied to make the dataset suitable for further analysis and reporting.

**🛠️ Tools Used**
Microsoft Power BI Desktop
Power Query Editor
Power Query (M) formulas

**🔄 Data Preparation Steps**
Imported the Superstore Sales dataset into Power BI.
Promoted the first row as column headers.
Verified and changed appropriate data types.
Applied locale-based date formatting.
Trimmed and cleaned text values.
Created Year column from Order Date.
Created Quarter column.
Created Month and Month Name columns.
Created Day column.
Created Day Name column.
Created custom columns using Power Query formulas.
Created custom Month, Day, Day of Week, and Quarter fields.
Reviewed the Applied Steps to verify the transformation process.

**📊 Key Transformations**
The Order Date field was used to derive multiple time-related columns, including:
Year
Quarter
Month
Month Name
Day
Day Name
Day of Week
These fields provide a structured foundation for future time-based sales analysis.

**📁 Dataset**
**Superstore Sales Dataset**
The dataset contains information related to:
Orders
Customers
Shipping
Products
Categories
Sales
Geographic information

**🎯 Objective**
The main objective of this project is to develop a clean and well-structured dataset in Power BI that can be used for sales analysis, visualization, and dashboard creation.

**✅ Conclusion**
The Superstore Sales dataset was successfully imported and prepared using Power Query. Data types were standardized, text values were cleaned, and multiple date-based columns were created to support detailed analysis in Power BI.
